COMO USAR ESTA PASTA

1) Abra a pasta P2_revisao_completa no VS Code.
2) Entre em qualquer pasta de exercício.
3) Rode com node.

Exemplos:
node 01_fila_pilha/exer01_fila_clinica.js
node 02_buscas/exer01_busca_sequencial_placas.js
node 05_avl/exer03_4_casos_avl.js
node 08_simulados/simulado01_misto.js

Tudo está em CommonJS usando require/module.exports para evitar misturar import com require.

Se o professor der um enunciado novo:
1) leia as palavras-chave;
2) descubra a estrutura;
3) copie um exercício parecido;
4) troque apenas os valores e os nomes das variáveis.
